安裝到主畫面

iPhone 用 Safari

  1. 從 LINE 點開的話，先點右上角選單，選「用預設瀏覽器開啟」。
  2. 用 Safari 打開網址後，點右下角「⋯」，再點「分享」 。舊版 iOS 直接點下方中間的分享按鈕。
  3. 往下滑，點「加入主畫面」。
  4. 確認「打開為網頁 App」開著，按右上角「新增」。
  5. 回到主畫面，點紅色愛心圖示「血壓血糖」開始使用。
請先加到主畫面，再從圖示打開開始記錄。iPhone 上 Safari 和主畫面圖示的紀錄是分開存的。

Android 用 Chrome

  1. 用 Chrome 打開網址。
  2. 點右上角「⋮」。
  3. 點「加到主畫面」或「安裝應用程式」，再按「安裝」。
  4. 回到主畫面，點「血壓血糖」圖示開始使用。

可以做什麼

  • 大字數字鍵像撥電話一樣按數字，不用打字。
  • 血壓、血糖分開記空腹、飯後、睡前都能選，量完馬上告訴你是否在理想範圍。
  • 趨勢圖7、30、90 天的變化和趨勢線，看診時一目了然。
  • 一鍵複製報告貼到 LINE 給家人或醫師。

紀錄放在哪裡？

紀錄只存在您自己的手機，不會上傳到任何人的伺服器，開發者也看不到。

想要備份或換手機，可以在 App 的「設定」連接您自己的 Google 雲端硬碟，或匯出備份檔自己保存。

可以設定四碼鎖，避免別人拿起手機就看到紀錄。詳細隱私權說明與聯絡方式
